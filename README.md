# 🦝 Енотов Ежедневник

Первый проект Telegram Mini App.
Персональный планер с трекингом задач, привычек и дневником. Работает как Telegram Mini App — открывается кнопкой прямо в чате с ботом, без установки.

🤖 **Бот:** [@Raccoons_Diary_bot](https://t.me/Raccoons_Diary_bot)

---

## ✨ Возможности

| Раздел | Описание |
|--------|----------|
| 📋 **День** | Задачи на выбранный день, прогресс-кольцо, отметка выполнения |
| 📅 **Неделя** | Обзор 7 дней с прогресс-барами, быстрый переход |
| 📝 **Дневник** | Сон, энергия, настроение, урок дня, благодарность, заметки |
| 📊 **Аналитика** | Статистика по категориям, средний сон, процент выполнения |
| 🔔 **Уведомления** | Утренние и вечерние напоминания через бота |
| 💾 **Бэкап** | Экспорт и импорт данных в JSON |

---

## 🚀 Быстрый старт

1. Открой бота [@Raccoons_Diary_bot](https://t.me/Raccoons_Diary_bot)
2. Нажми кнопку **«Ежедневник»** внизу чата
3. Приложение откроется внутри Telegram

---

## 🔔 Уведомления

Бот присылает напоминания по расписанию:
- 🌅 **Утро** — список задач на день (настраивается в Mini App)
- 🌙 **Вечер** — напоминание заполнить дневник

Настройки времени — в разделе ⚙️ Настройки Mini App.


---

## 🛠 Технологии

- **Telegram Mini App** — WebApp API, нативная интеграция
- **HTML + CSS + JavaScript** — ванильный стек, без фреймворков
- **Supabase** — облачная PostgreSQL база данных
- **Render** — хостинг Telegram-бота (Node.js)
- **GitHub Pages** — хостинг Mini App


---

## 📱 Как это работает

Бот и база данных — в отдельных репозиториях:
- Бот: `Raccoon-s-DiaryBot` (Render)
- База: Supabase проект

---

## 💾 Бэкап данных

Данные хранятся в двух местах:
1. **localStorage** — в браузере телефона (быстро, офлайн)
2. **Supabase** — в облаке (синхронизация между устройствами)

Экспорт/импорт JSON — в настройках, на случай если нужно перенести данные вручную.
